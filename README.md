# 🎮 GuessMaster

A terminal-based Number Guessing Game built with Python.

**Current Version:** **v1.0.0**

---

# 📖 Project Description

GuessMaster is a beginner-friendly Python terminal game where the player has to guess a randomly generated number between **1 and 50**.

After every guess, the game provides a helpful hint indicating whether the guess is **Too High** or **Too Low**. The game continues until the player guesses the correct number, after which a final report and performance rating are displayed.

This project was created as part of my Python learning journey to strengthen my understanding of programming fundamentals by building a practical mini-project.

---

# ✨ Features

- 🎲 Randomly generates a secret number between **1 and 50**
- 🎯 Unlimited guessing attempts
- 📈 Too High hint
- 📉 Too Low hint
- 🔢 Attempt counter
- 📋 Final game report
- ⭐ Performance rating based on total attempts
- 🔄 Play Again option
- ✅ Input range validation (1–50)
- 💻 Clean terminal-based interface

---

# 🎮 How to Play

1. Run the program.
2. Read the game rules displayed on the screen.
3. Enter a number between **1** and **50**.
4. The game will tell you whether your guess is:
   - Too High
   - Too Low
5. Keep guessing until you find the correct number.
6. View your final report and performance rating.
7. Choose to play again or exit the game.
